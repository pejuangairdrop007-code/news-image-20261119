A newspaper-poster image summing up Thursday 19 November 2026 in six
stories: the Shenzhen peace declaration, the ICJ genocide ruling on
Myanmar, tankers hit in the Strait of Hormuz, COP31 in Antalya,
unrest in Bangladesh, and Bank Indonesia's rate hike to 6%.

`gen_image.py` draws `entry.png` (1024x1024, deterministic, Pillow only).
`main.py` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` using
only the Python standard library.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
